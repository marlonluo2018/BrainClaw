- No separate file needed

**For Larger Groups (5+ learners):**
- Create a separate file for the learner list
- Benefits: Easier tracking and reference

1. Wait for quarterly notification email from Yi Kuan Chiew
2. Access the Q2 reimbursement list via provided link
3. Enter learner names who completed training/certifications in Q2
4. Use direct entry (small lists) or separate file (larger groups)
5. Submit before end of quarter
